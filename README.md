# METRIC / LIFE OS

一个面向个人生活管理的前端实验项目。它把待办、工作计薪、六维成长、行动清单和健康复查放在同一个生活仪表盘里，所有初始展示数据和界面文案都从 `public/metric` 下的静态文件读取，不使用后端服务；交互数据使用浏览器 IndexedDB 保存。

## 模块

- **总览**：今日焦点、状态分、统计指标、Todo List 和季度 OKR。
- **打工赚钱**：只要处于当天配置的工作时段，就按时间实时累计收入；工作状态仅用于个人记录，并支持每日被动收入和累计曲线。
- **六维成长**：体能、专业、思维、学识、爱好和自由六个维度，从 10 分起步，以 20 分作为正常参考线，记录事件加分并查看日、周、月变化。
- **任务清单**：体态纠正、有氧走路、室内跑步和深度工作等动作清单，可逐项勾选。
- **健康复查**：配置检查大类、小类和正常范围，按日期录入本次结果、医生建议与 AI 建议，并查看每项指标趋势。

## 技术栈

- React 19 + TypeScript 6 + Vite 8
- Lucide React 图标
- Recharts 雷达图与趋势折线图
- Oxlint 静态检查

## 数据约定

```text
public/metric/
├── dashboard.json  # 总览、导航、用户资料、Todo、OKR
├── work.json       # 大刀工作页的计薪参数、商品和工作状态
├── work-yuanyuan.json # 圆圆工作页的独立计薪参数、商品和工作状态
├── growth.json     # 六维分数、周变化和信号
├── rituals.json    # 清单和动作
├── health.json     # 检查大类、小类、正常范围和示例记录
└── ui.json         # 加载态、辅助标签、提示语和格式化单位
```

页面加载时通过 `fetch('/metric/*.json')` 读取这些文件。Todo、工作状态、清单动作、每日被动收入、成长分数与事件、新增健康记录和每日基础值会保存到当前浏览器的 IndexedDB，刷新页面后会优先恢复本地数据；计薪秒数仅在当前页面运行时根据本地时间和工作时段计算，不写入 IndexedDB；首次使用时才使用 JSON 中的初始状态。

顶栏的同步按钮和重置按钮都只作用于当前活动页面对应的单个 JSON 文件：总览对应 `dashboard.json`，打工赚钱对应 `work.json`，六维成长对应 `growth.json`，任务清单对应 `rituals.json`，健康复查对应 `health.json`。同步会把当前页的 IndexedDB 状态写回对应文件；支持目录写入的浏览器会在用户授权 `public/metric` 后直接覆盖文件，其他浏览器会下载当前 JSON 文件，手动替换回 `public/metric` 即可。重置会读取当前对应 JSON，将该页的 IndexedDB 状态恢复为 JSON 值，不影响其他页面；六维成长没有 IndexedDB 交互状态，因此只能同步，不能重置。计薪秒数不会被同步到 JSON。

`work.json` 和 `work-yuanyuan.json` 分别对应工作页中的大刀和圆圆。工作页可以在两份 JSON 之间切换，圆圆只存在于 Work 页面，不作为其他页面的用户。两份文件都只需要填写各自的 `monthlySalary`。应用会按当前月份的周一至周五统计工作日，并根据 `09:00-12:00`、`13:30-18:30` 两个工作时段自动推导每天 8 小时、日薪和每秒工资；每天 09:00 开始按当前时间累计，18:30 停止并达到每日上限，跨过 24:00 后按新的一天从 0 开始。工作状态只用于个人记录，不影响收入计算。

健康 JSON 中的 `categories` 用于一次复查，包含血常规、尿常规、生化 27 项、药物浓度和病毒浓度；`dailyBaseItems` 与 `dailyBase` 用于每天记录体重、体脂、骨骼肌、血压和静息心率等基础值。
